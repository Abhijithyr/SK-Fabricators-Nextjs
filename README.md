# SK Fabricators - Next.js JavaScript

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run: `npm install`
4. Run: `npm run dev`
5. Open: http://localhost:3000

## Main files
- `app/page.js` - complete website UI and content
- `app/layout.js` - metadata and root layout
- `app/globals.css` - Tailwind CSS import and global styles

## Customize
Search `app/page.js` for `919876543210`, phone numbers, email, address, and SK Fabricators text and replace them with your real details.
